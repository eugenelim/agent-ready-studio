# Architecture

These living documents describe how the current code is organized and the
rules new work follows.

- [`overview.md`](overview.md) maps the applications, packages, state owner,
  and complete request path. Read it first when locating a change.
- [`reference.md`](reference.md) is the normative architecture for dependency,
  persistence, protocol, Electron, and validation decisions.
- [`../adr/`](../adr/) records why the foundation choices were made.

Architecture documents are living. Update them when ownership, a major
dependency edge, state flow, or an entry point changes.
